# Estilos de diagramas

Estado: [base.puml.inc](base.puml.inc) es el estilo documental compartido de fase 3, comprobado con PlantUML local y revisado visualmente. Solo afecta fuentes UML; no modifica configuración de la aplicación. Se utiliza el trazado predeterminado para que Graphviz reserve espacio a etiquetas; se retiró el trazado ortogonal que producía superposiciones.

[Registro](../README.md) y [convenciones](../convenciones-uml.md).
