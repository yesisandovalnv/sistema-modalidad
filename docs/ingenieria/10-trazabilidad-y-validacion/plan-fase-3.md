# Recomendaciones para fase 3

Estado histórico: propuesta de fase 2, posteriormente autorizada por el usuario para fase 3. Los resultados y pendientes actuales están en [validacion-fase-3.md](validacion-fase-3.md).

1. Acordar si se modela HEAD o directorio de trabajo, explicitando DISC-007. No corregir políticas desde documentación.
2. Conciliar antecedentes para evitar reutilizar afirmaciones obsoletas.
3. Autorizar herramientas necesarias y fijar versiones; no instalar automáticamente.
4. Priorizar componentes y despliegue Docker declarado; después clases y ER modular.
5. Definir pregunta, alcance y evidencia de cada DIA; reservar vistas específicas por modalidad.
6. Contrastar modelos/migraciones para cardinalidades. PostgreSQL solo con autorización y lectura.
7. Revisar coherencia y legibilidad antes de ampliar a actividades y secuencias.

Criterios propuestos: evidencia por relación, reglas específicas separadas, referencia reproducible, enlaces válidos, IDs únicos y clasificación visible. No iniciar Docker, migraciones o pruebas de producto para generar documentación sin analizar efectos y autorización.

Esta propuesta no autoriza fases posteriores ni modificaciones funcionales. Los documentos exteriores a docs/ingenieria/ permanecen intactos.
